Drop the 8 coverage cover images here, named exactly by product slug. The
homepage coverage cards read `/covers/<slug>.jpg`; until a file exists, a
branded placeholder shows, so a missing image never looks broken.

| Order | File name                            | Coverage                     |
| ----- | ------------------------------------ | ---------------------------- |
| 1     | `ai-liability.jpg`                   | AI Liability                 |
| 2     | `agentic-eo.jpg`                     | Agentic E&O                  |
| 3     | `energy-infrastructure.jpg`          | Energy Infrastructure        |
| 4     | `data-centers-pc.jpg`                | Data Centers P&C             |
| 5     | `tech-enterprise-do.jpg`             | Tech Enterprise D&O          |
| 6     | `humanoids.jpg`                      | Humanoids                    |
| 7     | `autonomous-vehicles.jpg`            | Autonomous Vehicles          |
| 8     | `autonomous-machinery-failure.jpg`   | Autonomous Machinery Failure |

A PNG renamed to `.jpg` is fine; browsers render by content, not by extension.
